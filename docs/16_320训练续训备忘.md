## 320 实验结论（2026-10-21，负结果）

**320 对部署场景无收益，不采用。**

| 配置 | 带作物先验（去重 225） | 裸 acc（真实域 val） |
|---|---|---|
| 224 部署权重 | 76.9% (173/225) | 53.98% |
| 320 权重 | **76.9% (173/225)** | 56.93%（epoch1 峰值） |

- 320 提升的是**不指定作物时的跨作物区分**（裸 acc +2.95pp）；
- 部署主路径是**用户指定作物**，作物先验已解决跨作物错误 → 320 优势被抵消，带先验 0 提升；
- epoch1 后裸 val 反降（56.93→55.16→53.98），已过拟合；
- 结论：为 0 收益付出推理翻倍 + OOD 头重训 + 校准重拟，**不划算，回退 224**。

**真正瓶颈**：番茄类内病害区分（带先验仍低）。下一步应走 **E（补番茄真实标注）** 或 **D（换更大骨干 ResNet50）**，而非继续加分辨率。
