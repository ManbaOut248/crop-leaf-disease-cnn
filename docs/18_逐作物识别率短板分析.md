| 口径 | 最低的作物 | 准确率 | 是否需要担心 |

## 4. 为什么偏偏是番茄

### 原因一：番茄是候选类别最多的作物（决定性因素）

番茄一作占 **10 个类别**，是 38 类里的 26%。作物先验的作用是「把 softmax 限制在该作物的候选类内」，
候选越多，先验能砍掉的错误分支就越少：

| 作物 | 候选类数 | 先验效果 |
|---|---:|---|
| 柑橘 / 蓝莓 / 树莓 / 大豆 / 南瓜 | **1** | 掩码后唯一候选 → 几乎必对（故表中 100%） |
| 樱桃 / 桃 / 甜椒 / 草莓 | 2 | 砍掉 36 个类，收益极大 |
| 马铃薯 | 3 | 收益大 |
| 玉米 / 苹果 / 葡萄 | 4 | 收益中等 |
| **番茄** | **10** | **仅砍掉 28 个类，仍剩 10 选 1** |

> 也就是说：**表中 7 个作物 100% 的成绩，有相当一部分是「候选唯一」的先验红利，不是模型本身强。**
> 番茄没有这个红利，所以它的 43.9% 更接近"模型对细粒度病害的真实判别力"。

实测佐证（`outputs/crop_prior_report.json`）：多候选作物整体 15.8% → 43.6%（先验 +27.7pp），
但番茄这类 10 候选作物仅 22.9%。

### 原因二：番茄内部病害症状高度重叠

细菌性斑点病 / Septoria 叶斑病 / 早疫病 / 靶斑病，在真实照片里都表现为
「叶片上若干褐色小斑点 + 周围黄化」，差异要靠斑点大小、同心轮纹、边缘颜色这些**很细的线索**。
模型在 PlantVillage 的 224px 黑底图上能分开（98.6%），换成真实照片的复杂背景 + 遮挡后就分不开。

### 原因三：「番茄（健康）」被误判成病害（37.5%）

真实田间的健康叶片往往带虫咬孔、尘土、水渍、阴影、多叶重叠，
而模型对"健康"的判别高度依赖"干净无斑"这一表层特征 —— 稍有瑕疵就判成病害。
这条在其它作物的健康类上同样成立（见 `docs/05_测试报告.md` 第 11.3 节）。

### 原因四：真实标注数据量最少

混合微调时番茄类补进了真实标注，但每类只有 3~10 张（PlantDoc 原始规模就这么大）。
番茄 10 个类合计才 66 张评估图，训练侧同样稀疏 —— 数据量决定了上限。

### 原因五：输入侧已无可挖空间（2026-10-26 实验证伪）

一个常见假设是"真实照片背景杂乱，先把叶片裁出来就能提升"。**实测否定**：

- 番茄 66 张里 **61 张（92%）的 OOD 叶片概率 ≥ 0.90**，本身就是单叶特写，没有背景可裁；
- 这些"干净图"的准确率也只有 **28/61 = 45.9%**；
- 再裁紧 40%（保留 36% 面积）→ **−4.5pp**；滑窗取最自信块 → **−10.6pp**。

**含义**：不是"没拍好"，是"病害之间分不开"。任何输入侧的裁剪 / 预处理都不能救，
详见 `docs/21_裁剪有效性实验.md`（含 6 种策略对照与 McNemar 检验）。

## 5. 改进建议（按性价比排序）

| 优先级 | 措施 | 预期 | 代价 |
|---|---|---|---|
| 高 | **番茄类补真实田间标注**（每类 ≥100 张，可用 PlantDoc + 自采） | 直接抬高上限，是唯一根治手段 | 需标注人力 |
| 高 | **番茄做二阶段分类**：先判「病害 / 健康」，再在 8 个病害类内细分 | 可修掉健康类 37.5% 那部分错误 | 需改推理链路 |
| 中 | **`IMAGE_SIZE=320` 高精度模式** | 番茄 43.9%→56.1%、整体 +3.1pp（76.9%→80.0%）；⚠️ 番茄上 p=0.153，统计未达显著 | GPU 单张几乎无感（12.5→12.2ms），纯 CPU 1.64× |
| 中 | **番茄类结果强制提示复核**：置信度 <0.55 或 reliability=low 时显式提示 | 降低"自信地错"的伤害 | 前端已有分档，只需调文案 |
| 低 | 提高番茄类训练样本的采样权重 | 小幅提升 | 可能加剧其它类退化 |

**已验证无效、不要重复踩的坑**（详见 `docs/11`、`docs/14`、`docs/21`）：

- **AdaBN / 温度缩放**：AUROC 对单调变换不变，排名不变 → 对"分不开"原理上无效（实测 0.5864→0.5045，反而更差）
- **改 38 类模型参数去适应真实域**：跷跷板效应，PlantVillage 精度 99.34% → 86.89%
- **同源数据增强扩量**：缺的是来源广度不是密度，对 OOD/真实域泛化几乎无效
- **裁剪 / 滑窗 / 多视图集成**：番茄上分别 −4.5pp / −10.6pp / +7.6pp(p=0.182，且 320 下反向 −7.6pp)，
  换分辨率就失效的改动不能进产品（`docs/21`）
