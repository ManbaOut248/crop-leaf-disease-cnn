## 3. 本机网络实测结果（重要）

### 3.1 各源连通性

| 源 | 可达 | 实测速度 | 备注 |
|---|:--:|---|---|
| **GitHub 直连** | ❌ | `HTTP 000` | 完全不通 |
| **ghproxy.net**（GitHub 代理） | ✅ | **≈10 KB/s** | 能下但很慢 |
| gh-proxy.com / ghfast.top | ✅ | ≈10 KB/s | 同上（HEAD 200，实际下载慢） |
| Zenodo | ❌ | `HTTP 000` | 不通（PlantVillage v2 托管在此） |
| challenger.ai | ❌ | `HTTP 000` | 不通（AI Challenger 在此） |
| Roboflow | ⚠️ | `HTTP 403` | 需登录认证 |
| **ModelScope 魔搭** | ✅ | 快 | 国内源，有数据集 API |
| **hf-mirror.com** | ✅ | 快（曾遇 429 限流） | HuggingFace 国内镜像 |
| **阿里云天池** | ✅ | 快 | 有 PlantVillage：[dataset/160100](https://tianchi.aliyun.com/dataset/160100) |
| **百度网盘** | ✅ | 快 | 有网友打包的 PlantDoc（见 3.3） |

### 3.2 通用：通过 ghproxy 下 GitHub 数据集

```cmd
curl -L -o PlantDoc.zip "https://ghproxy.net/https://github.com/pratikkayal/PlantDoc-Dataset/archive/refs/heads/master.zip"
```

> ⚠️ 实测速度约 **10 KB/s**，PlantDoc 仓库约 200 MB → 预计 **5 小时以上**，不建议直接全量拉取。
> 只取少量样本做验证时才实用。

### 3.3 更快的国内路径

| 路径 | 操作 | 说明 |
|---|---|---|
| **百度网盘** | 用网盘客户端打开分享链接 | PlantDoc 30 类 YOLO 格式约 4,900 张（社区打包版），速度取决于会员 |
| **阿里云天池** | 打开 [dataset/160100](https://tianchi.aliyun.com/dataset/160100) → 登录 → 下载 | PlantVillage，国内 CDN 速度快 |
| **ModelScope** | `www.modelscope.cn` → 搜「植物病害 / plant disease」 | 国内源，可 API 下载 |
| **hf-mirror** | `hf-mirror.com` 搜数据集 | 需配合 `HF_ENDPOINT=https://hf-mirror.com` 环境变量 |

## 4. 对本项目最实用的建议

### 4.1 别重复下 PlantVillage
项目已有 54,303 张，且已做过防泄漏切分（`data/split/`）。再下一份只是浪费磁盘。

### 4.2 真正缺的是「你自己会拍到的照片」

OOD 阈值（MSP 0.98 / 色度 8.0）是在 PlantVillage 的黑底实验室图上标定的，**而你的用户是在田间用手机拍**。两者分布差异很大。

**最有效的做法：用手机拍 30~50 张田间的叶片照片**（背景杂乱、不同光照、含几张明显不是叶子的），然后：

```cmd
cd /d "F:\WorkBuddy工作空间\基于CNN的农作物叶片病害识别系统"
py -3.12 scripts/eval_ood.py --n-in 500
```

用真实照片重跑评估，看误杀率实际是多少，再决定阈值要不要放宽。

> **为什么这比下几千张网图更有用**：要标定的不是"网上的图长什么样"，而是"**你的用户会传什么样的图**"。
> 几十张自己拍的照片，比 2,569 张印度田间的 PlantDoc 更贴合你的场景。

### 4.3 若要扩充训练数据
PlantDoc 更适合作为**难例**加入（真实田间、背景复杂），可显著提升模型在真实场景的鲁棒性。但它只有 2,569 张且类别体系与 PlantVillage 不完全一致（30 类 vs 38 类），**需要做类别对齐与清洗**，工作量不小。

## 5. 一句话总结

| 目的 | 怎么做 |
|---|---|
| 扩充实验室样本 | 不需要 —— 已有 PlantVillage 54,303 张 |
| 提升真实场景鲁棒性 | 优先**自己拍**；其次想办法拿 PlantDoc（网盘/天池比 GitHub 代理快得多） |
| 重标定 OOD 阈值 | **必须用真实拍摄照片**，不能用网图替代 |
| 写报告引用数据集 | 注意署名：PlantVillage (CC0) / PlantDoc (**CC BY 4.0 需署名**) |
