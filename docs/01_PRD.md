# 基于 CNN 的农作物叶片病害识别系统 — 产品需求文档（PRD）

> 版本：V1.0（设计阶段 M1）
> 关联文件：项目任务书 V1.0.0、要求.txt、UI/UX 设计、数据库设计、API 接口文档
> 类别口径：经与需求方确认，采用**真实数据集 38 类**（任务书文字写「26 类」，实测数据集为 PlantVillage 38 类 / 54,420 张，任务书「约 5.4 万张」与 38 类一致，「26 类」视为笔误）

---

## 1. 产品概述

### 1.1 背景
农作物病害是制约粮食与经济作物稳产增产的重要因素。传统诊断依赖农技人员肉眼观察，经验依赖强、基层力量不足，常错过最佳防治窗口。基于卷积神经网络（CNN）的叶片病害分类在公开数据集上已达接近专家水平。本项目以 ResNet18 为骨干，构建 Web 端识别应用，农户/农技人员手机拍照上传即可获得病害判读与防治建议。

### 1.2 总体目标
开发一款基于 ResNet18 的农作物叶片病害识别 Web 应用：用户通过浏览器上传叶片图像 → 系统自动识别病害类别（覆盖 **14 种作物、38 类病害及健康状态**）→ 返回置信度、Top-3 候选概率分布与防治建议。

### 1.3 量化指标（对齐任务书 2.2.3）
| 指标 | 目标 |
|---|---|
| 总体分类准确率 | ≥ 85% |
| 各类别 F1 分数 | ≥ 0.80 |
| 单张推理耗时（GPU） | ≤ 300 ms（不含网络传输） |
| 支持图像格式 | jpg / png / jpeg / bmp |
| 输入分辨率 | 224 × 224（预处理后） |
| 浏览器兼容 | Chrome / Firefox / Safari / Edge 最新两个大版本 |

| 角色 | 场景 | 核心诉求 |
|---|---|---|

## 3. 功能需求清单（FR）

### 3.1 图像上传模块（FR-UP）
- FR-UP-01：支持点击选择与拖拽上传。
- FR-UP-02：校验格式（jpg/png/jpeg/bmp）与大小（≤ 10 MB/张）。
- FR-UP-03：上传后即时预览原图。

### 3.2 图像预处理模块（FR-PRE）
- FR-PRE-01：缩放至 224×224。
- FR-PRE-02：RGB 归一化（ImageNet 均值/方差）。
- FR-PRE-03：格式统一转换，异常图像给出友好提示。

### 3.3 深度学习识别模块（FR-CLS）
- FR-CLS-01：基于 ImageNet 预训练 ResNet18，38 分类输出。
- FR-CLS-02：返回预测类别、置信度（softmax 概率）。
- FR-CLS-03：返回 Top-3 候选类别及概率。
- FR-CLS-04：模型离线加载，服务启动即就绪。

### 3.4 结果展示模块（FR-RES）
- FR-RES-01：展示预测病害中文名 + 置信度。
- FR-RES-02：Top-3 概率条形图可视化。
- FR-RES-03：展示病害特征说明与防治措施建议（来自知识表）。
- FR-RES-04：附农技服务免责声明。

### 3.5 历史记录模块（FR-HIS）
- FR-HIS-01：登录用户可保存识别历史（图、结果、时间）。
- FR-HIS-02：列表查看、原图与结果对比。
- FR-HIS-03：支持导出（CSV/JSON）。

### 3.6 用户管理模块（FR-USR）
- FR-USR-01：注册（邮箱/用户名+密码）。
- FR-USR-02：登录 / 登出（JWT）。
- FR-USR-03：个人信息管理（昵称、修改密码）。
- FR-USR-04：密码加盐哈希存储，HTTPS 传输。

---

## 4. 非功能需求（NFR）
- NFR-PERF：并发识别请求经队列/批处理，P95 推理 ≤ 500 ms。
- NFR-SEC：用户密码 bcrypt/argon2 哈希；通信 HTTPS；上传图像不用于训练外的其他用途（任务书 6.2）。
- NFR-COMPAT：响应式布局，适配 PC 与移动端浏览器。
- NFR-LIMIT：对训练集外作物/病害、复杂田间光照、枝叶遮挡、混合侵染，明确提示「建议人工复核」（任务书 6.3）。

## 5. 技术架构概述
前后端分离 B/S 架构：
- **前端**：React + TailwindCSS/Ant Design，响应式。
- **后端**：FastAPI 提供 RESTful API（用户认证、预处理、推理、历史、知识查询）。
- **模型**：PyTorch ResNet18（ImageNet 预训练 + 迁移学习微调），推理服务常驻。
- **数据**：SQLite 持久化（用户、历史、病害知识、配置）。
- **部署**：单服务进程（uvicorn）+ 静态前端；可选模型量化/剪枝优化（任务书 3.3）。

## 6. 数据说明
- 数据集：PlantVillage（本地路径 `F:\实训产品\基于CNN的农作物叶片病害识别系统\PlantVillage`），**38 类 / 54,420 张**。
- 划分：训练:验证:测试 = 8:1:1（按类分层抽样）。
- 类别不均衡显著（Orange 黄龙病 5,507 张 vs Potato healthy 152 张）→ 采用 **类别加权损失 + 数据增强**（随机旋转、水平翻转、亮度/色彩扰动）。
- 38 类映射（作物 + 中文病名）见《数据库设计文档》`disease_knowledge` 表。

## 7. 模型方案
1. 加载 ImageNet 预训练 ResNet18，替换末端全连接层为 38 分类输出。
2. 损失：加权交叉熵；优化器：Adam；早停监控验证集准确率。
3. 评估：测试集整体准确率 + 各类别 Precision/Recall/F1 + 混淆矩阵。
4. 优化（任务书 3.3）：模型量化（int8）+ 结构剪枝，降低体积与推理耗时，保留精度可接受下降。

## 8. 验收标准（GIVEN-WHEN-THEN）
- **AC-01（准确率）**：GIVEN 测试集 38 类，WHEN 模型评估，THEN 整体准确率 ≥ 85% 且每类 F1 ≥ 0.80，否则迭代调参/增广。
- **AC-02（上传）**：GIVEN 用户上传合法 jpg/png，WHEN 提交，THEN 显示预览并可触发识别；非法格式/超尺寸给出明确错误。
- **AC-03（推理）**：GIVEN 已登录用户上传叶片图，WHEN 调用推理接口，THEN 返回类别+置信度+Top-3。
- **AC-04（历史）**：GIVEN 识别完成，WHEN 用户保存，THEN 历史列表可见且可导出。
- **AC-05（安全）**：GIVEN 未登录，WHEN 访问历史/个人信息，THEN 重定向登录；密码非明文存储。
- **AC-06（免责）**：GIVEN 展示结果，THEN 页面含农技服务免责声明。

---

## 9. 范围边界
**做**：Web 端 38 类识别、Top-3 可视化、防治知识、用户体系、历史、模型量化部署。
**不做**：原生移动 App；现场诊断替代；训练集外作物/病害识别；农药电商交易；多病害像素级分割。

---

## 10. 风险与应对
| 风险 | 应对 |
|---|---|
| 样本不均衡致小类 F1 不达标 | 类别加权 + 强数据增强 + 小类过采样 |
| 田间泛化差（光照/遮挡/混合） | 界面明确「建议人工复核」提示；推理阈值过低时返回「不确定」 |
| 8GB 显存训练受限 | batch_size 调至 64~128；混合精度(AMP)训练 |
| 任务书 26 类 vs 数据 38 类 | 已确认按 38 类，文档统一口径 |
| 用户隐私合规 | HTTPS + 密码哈希 + 数据用途声明 |
