# 17. 双分辨率模式（224 合规 / 320 高精度）

> 2026-10-23 ｜ 起因：320 分辨率使真实域 +3.1pp，但任务书 2.2-2 明确要求「224x224 像素」。

## 设计原则

- **默认 224×224**：与任务书 2.2-2 完全一致，验收无歧义。
- **320×320 高精度模式**：设环境变量 `IMAGE_SIZE=320` 启用，真实域带先验 76.9% → **80.0%**（+3.1pp），代价是推理延迟约翻倍。
- 两套 **权重 / OOD 头 / 校准文件** 完全隔离，切换模式不会互相污染。

## 文件组织

| 模式 | 权重 | OOD 头 | 真实域校准 |
|---|---|---|---|
| 默认 224 | `models/best_resnet18_38.pth` | `models/ood_head.npz` | `models/calibration_domain.json` |
| 高精度 320 | `models/best_resnet18_38_320.pth` | `models/ood_head_320.npz` | `models/calibration_domain_320.json` |

`src/config.py` 通过 `_MODE_SUFFIX` 按 `IMAGE_SIZE` 自动派生路径，无需手工改代码：

```python
_MODE_SUFFIX = "_320" if int(os.getenv("IMAGE_SIZE", "224")) == 320 else ""
BEST_MODEL_PATH = MODEL_DIR / f"best_resnet18_38{_MODE_SUFFIX}.pth"
OOD_HEAD_PATH   = MODEL_DIR / f"ood_head{_MODE_SUFFIX}.npz"
CALIBRATION_DOMAIN_PATH = MODEL_DIR / f"calibration_domain{_MODE_SUFFIX}.json"
```

## 切换方式

```cmd
:: 默认（224，符合任务书）
X:\Anconda3\python.exe -m uvicorn src.api.main:app --host 127.0.0.1 --port 8000 --no-proxy-headers

:: 高精度（320）
set IMAGE_SIZE=320
X:\Anconda3\python.exe -m uvicorn src.api.main:app --host 127.0.0.1 --port 8000 --no-proxy-headers
```

## 指标（去重 225 张真实域，带作物先验）

| 模式 | PlantVillage 测试集 | 真实域 | 推理速度 |
|---|---|---|---|
| **224（默认）** | 99.27% | 76.9% | 基准 |
| **320（高精度）** | 99.25% | **80.0%** | 约 2 倍慢 |

## 备注

- 两份权重都以同一 best 为起点；320 版为混合微调第 13 轮的最优检查点（真实域 val 63.13%）。
- 320 的 OOD 头与校准已用 320 特征/ logits 重做，**不可与 224 文件混用**（`_MODE_SUFFIX` 已隔离）。
- 回退：改回 `IMAGE_SIZE` 默认即可，两套文件并存无副作用。
