# 15. 真实域混合微调（Domain Mixed Finetuning）

> 目标：提升模型在**真实田间照片**（PlantDoc）上的精准度。
> 方案：**Plan A 混合微调**——PlantDoc 真实标注 + PlantVillage 合成图保底，保持 38 类契约不变。
> 完成日期：2026-10-20

## 1. 背景与诊断

实验室域（PlantVillage 测试集）准确率 99.27%，但真实田间照片（PlantDoc test）仅 17.5%（不指定作物）/ 52.5%（指定作物先验）。
逐类混淆诊断显示：**错误全部是「同作物内病害混淆」（57/57），0 例跨作物**——作物识别已被先验解决，瓶颈是同一作物下细分病害区分不开。

**根因定位（关键）**：旧真实数据 `outputs/realtest` 只覆盖 PlantDoc 22 类，**漏了 6 个病害类**：
番茄细菌斑病、番茄晚疫病、葡萄黑腐病、玉米锈病、马铃薯晚疫病、番茄红蜘蛛——正是之前「番茄病害类 0% / 葡萄黑腐 0%」的元凶，模型从未见过这些病害的真实标注。

## 2. 数据准备

- **数据源**：`github.com/pratikkayal/PlantDoc-Dataset`（官方镜像，28 类，CC BY 4.0，直连 GitHub 已通无需代理）
- **导出**：`scripts/export_plantdoc.py`（`git ls-tree` + `cat-file --batch` 批量导出，绕过 Windows 文件名非法字符 `?`、超长路径 `MAX_PATH=260`、管道死锁三连坑）
- **映射**：PlantDoc 官方 28 类 → 38 类完整映射（缺失的 9 个 38 类用 PlantVillage 合成图保底）
- **混合索引**：`scripts/prepare_plantdoc_mix.py` 生成
  - 训练：`dataset_index_mixed.json`（train **46811** = PV 44470 + 真实 2341；val 4921；test 4914）
  - 真实域评估：`data/real_mix_test`（**497 张**，28 类，md5 去重 + 剔除官方 train/test 重叠 11 张，严格防泄漏不进训练）
- **评估集纯洁性**：PlantDoc 源有内部重复、官方 train/test 有 11 张重叠，已去重 + 剔除，保证评估不偏乐观、不污染训练

## 3. 训练

- 脚本：`scripts/finetune_domain.py`
- 起点：`best_resnet18_38.pth`（99.27%）
- 配置：LR `5e-5` + 类别均衡采样 + 混合数据，GPU RTX 4060（torch 2.5.1+cu121）
- **早停以 PV val F1 为准**（守住实验室域精度，避免域适应回退）
- 产物：`models/finetuned_resnet18_38.pth`（检查点格式 `{'model', 'val_f1', 'real_test_acc', 'epoch'}`，与部署兼容）
- 最优检查点：epoch 3，val_f1 = **0.9933**

## 4. 结果（同一评估集 data/real_mix_test，225 张以上，带作物先验）

| 指标 | 微调前 (best) | 微调后 (finetuned) | 变化 |
|---|---|---|---|
| **真实域 Top-1（去重 225 张，带作物先验）** | 52.9% (119/225) | **75.6% (170/225)** | **+22.7pp** |
| 同上（目录 497 文件，含重复） | 54.1% (269/497) | 76.7% (381/497) | +22.6pp |
| 实验室域 val_f1 | 99.27% | **99.33%** | 不退化 ✓ |
| 真实域裸 acc（无先验） | — | 46.7% (epoch3) | — |

**逐类提升（去重 225 张口径，典型翻车类 → 翻身后）**：
- 葡萄黑腐 25% → **100%**、桃健康 33% → **100%**、草莓健康 38% → **100%**、樱桃健康 80% → **100%**
- 苹果桧锈 20% → **80%**、马铃薯晚疫 40% → **80%**、玉米普通锈 30% → **90%**
- 番茄 Septoria 0% → **70%**、番茄健康 25% → 50%
- **少数退步**：番茄黄卷叶 40% → 20%、马铃薯早疫 86% → 57%、玉米灰斑 100% → 67%、番茄晚疫 60% → 50%
  （同一作物内病害互相挤占的典型现象，整体净收益仍 +22.7pp）

## 5. 意外收益：置信度也更准了

混合微调不仅提升准确率，还让模型在真实域**不再过自信**——校准温度从 `T=6.05/9.55` 骤降到 `T=1.10/1.20`（模型学会了真实病害长相，logits 分布本身更 calibrated）。详见 `docs/14_置信度校准.md`。

## 6. 部署与回退

- **已替换部署权重**：`models/best_resnet18_38.pth` ← `finetuned_resnet18_38.pth`（2026-10-20 16:10）
- **原权重备份**：`backups/2026-10-20-pre-finetune/models/best_resnet18_38.pth`
- 权重文件被 `.gitignore` 忽略（不入库，本地部署用本地替换）
- 微调后已重拟合校准温度（`models/calibration_domain.json` → T_global=1.10 / T_crop=1.20）

## 7. 复跑命令

```bash
# 1) 克隆并导出 PlantDoc（若 data/plantdoc_raw 不存在）
git clone https://github.com/pratikkayal/PlantDoc-Dataset.git data/plantdoc_raw/PlantDoc-Dataset
python -m scripts.export_plantdoc          # 绕过 Windows 文件名坑导出到 data/plantdoc_raw/exported

# 2) 构建混合训练集 + 评估集
python -m scripts.prepare_plantdoc_mix

# 3) 混合微调（GPU）
python -m scripts.finetune_domain

# 4) 重拟合置信度校准温度（权重变了必须重做）
python -m scripts.calibrate_domain

# 5) 真实域评估（带作物先验，对比 best）
python -m scripts.eval_realtest --weights models/finetuned_resnet18_38.pth
python -m scripts.eval_realtest                            # 现状基准 best
```
