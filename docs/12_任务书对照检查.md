## 1. 一个容易误读的地方：26 类还是 38 类

任务书写「14 种作物共 **26 类病害**及健康状态」，代码里是 **38 类**。这不是偏差：

```
38 类 = 26 个病害类 + 12 个健康类，覆盖 14 种作物
```

与任务书完全对应（"26 类病害 **及健康状态**"）。答辩时若被问到，按上式回答即可。

| 项 | 任务书 | 实际 |
|---|---|---|
| 作物 | 14 种 | **14 种**（Apple / Blueberry / Cherry / Corn / Grape / Orange / Peach / Pepper / Potato / Raspberry / Soybean / Squash / Strawberry / Tomato） |
| 病害类 | 26 | **26** |
| 健康类 | 有 | **12** |
| 总类别 | — | **38** |
