## 1. 画布与母版

- **画布**：1280 × 720 px（16:9）。
- **安全边距**：左右 40；上下按母版区。
- **母版模式**：全篇锁定 **A3**（深蓝顶条 + 内容页默认样式）。

| 区域 | 范围 | 规则 |
| :-- | :-- | :-- |
| A 页眉条 | y 0–56 | 深蓝 `#0E3F8C` 实色；左「🌿 农作物叶片病害识别系统」白字 15px；右章节标签白字 15px |
| B 标题块 | y 76–124 | 主标 36px Bold `#0E3F8C`，左对齐 x=40；下方 2px 分隔线 `#D6DCE5`（y≈132） |
| C 内容区 | y 140–652 | 宽 1200（x 40–1240），高 512；背景仅 `#FFFFFF` / `#F7F9FC` |
| D 页脚 | y 660–700 | 左「前沿技术实训 · 2026」14px `#8B97A8`；右页码 `NN / 15` 15px Bold `#1E4FA8` |

- **封面 / 章节扉页 / 感谢页**：省略 B 标题块，可自定义构图（扉页保留顶条与页脚）。
- **页码**：内容页与扉页均标注 `NN / 15`。

| 层级 | 字体 | px | 字重 |
| :-- | :-- | :-- | :-- |
| 封面中文主标 | Microsoft YaHei | 62 | Bold(700) |
| 封面英文副题 | Times New Roman | 42 | Bold(700) |
| 页面主标（B 区） | Microsoft YaHei | 36 | Bold(700) |
| 章节扉页巨型数字 | Microsoft YaHei | 200 | Bold(700) |
| 卡内标题 | Microsoft YaHei | 26 | Bold(700) |
| 正文 | Microsoft YaHei | 22 | Regular(400) |
| 表格 / 表头 | Microsoft YaHei | 19 | Regular / Bold |
| KPI 巨数字 | Microsoft YaHei | 72 | Bold(700) |
| 注解 / 页脚 / 页码 | Microsoft YaHei | 14–15 | Regular |

**字体家族仅 2 套**：`Microsoft YaHei`（中文与西文正文，思源黑体的 Windows 等价落地）+ `Times New Roman`（仅封面英文长标题）。禁楷体、行书、艺术字、3D 字。
**正文最低 22px，卡内标题最低 26px**（不得低于学术风下限）。

**相对预设的微调（显式声明）**：
1. 预设要求「思源黑为主」，本项目落地为 **Microsoft YaHei**（Windows 答辩机无思源黑时零降级风险，保证不出现豆腐块）。
2. 预设封面英文用 Bold Serif → 采用 **Times New Roman Bold**，与学术论文观感一致。
3. 全篇以**真实产品界面截图 + 数据集真实叶片图**为 L1 主视觉（预设要求的"真实摄影 / 实验图"），禁用插画与 3D。

## 4. 信息密度与组件

### 4.1 密度基线

- 内容页 C 区宽 1200、累计高 ≥ 512px（≥71% 可用高），元素不得集中在中央 60% 区域。
- 卡片填充率 ≥80%；单行多卡等高，兄弟卡高差 ≤8px。
- 卡内 padding：上下 16、左右 20；正文允许软换行，禁止溢出。
- 正文页至少复用 **3 类组件**（卡体 / 标签 / 强调条 / 表格 / 图标 / 数据块）、≥3 个内容层次。
- 仪式段（封面 / 扉页 / 感谢页）留白 ≤35%；内容页禁用大留白。

### 4.2 组件族（本项目实际使用）

| 组件 | 规格 |
| :-- | :-- |
| 卡体 | 淡描边卡 TC-6：底 `#FFFFFF` 或 `#F0F5FC`，1px `#D6DCE5` 描边，圆角 8；深蓝实色卡单页 ≤1、全篇 ≤3 |
| 编号方块 | 深蓝 `#1E4FA8` 实底 + 白字，36×36，圆角 6 |
| 药丸标签 | 浅蓝 `#E8EFF8` 底 + `#1E4FA8` 字，圆角 999，高 26 |
| 底部强调条 | 深蓝 `#0E3F8C` 底 + 白字，左 4px 黄色竖条，全宽（核心金句条单页 ≤1） |
| 表格 | 深蓝表头 `#0E3F8C` 白字 + 斑马纹 `#F0F5FC`，关键格浅黄 `#FFF6DA` 高亮 |
| 图标 | Font Awesome 线框图标，统一 28×28，主蓝或藏蓝着色 |
| 数据块 | KPI 数字 72px Bold `#1E4FA8` + 注释 15px `#8B97A8` |
